What the platform predicts

  • Permission risk — calibrated refusal probability with risk bands (low / medium / high)
  • Process friction — further-information likelihood, third-party and applicant appeal risk, clean-outcome probability, six-month decision tail
  • Grant conditions — pre-commencement and financial condition probabilities
  • Refusal grounds — multi-label theme exposure: if refused, on what grounds, with per-theme confidence
  • Rescue plan — historically-supported resubmission changes and their measured conversion rates
  • Market context — price benchmarks, competing supply within 3 km, site planning history, authority baselines

Validation

Validated on an untouched holdout of 35,713 applications from 2024-2025: predicted refusal rates track observed refusal rates with calibration error averaging ±0.9 percentage points, with maximum decile-level miscalibration of 1.9 percentage points. Full validation studies — outcomes against simple historical baselines, timelines against medians, and a housing-supply backtest — are in docs/VALIDATION_STUDIES.md.

Run it yourself

pip install -r requirements.txt
python 09_devrisk/scripts/run_report_engine.py 09_devrisk/scripts/inputs_example.json

The engine reads only the frozen report bundle — no network, no live data, no runtime training. Give it a proposal and it produces the same 18-section underwriting review shown above.
